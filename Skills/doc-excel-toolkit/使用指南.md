## 支持的文件类型

### 文档分析
- PDF (.pdf) - 使用 pdfplumber 提取文本
- Word (.docx) - 使用 python-docx 处理段落和表格
- 文本 (.txt) - 直接读取，自动检测编码

### Excel 处理
- Excel 2007+ (.xlsx) - 使用 openpyxl
- 旧版 Excel (.xls) - 使用 xlrd
- 逗号分隔值 (.csv) - 使用 pandas

## 功能特性

### 文档分析
- 文本提取和内容总结
- 关键词搜索
- 表格提取
- 编码自动检测

### Excel 处理
- 数据读取和分析
- 统计摘要生成
- 数据筛选和排序
- 文件创建和修改
- 多工作表支持
