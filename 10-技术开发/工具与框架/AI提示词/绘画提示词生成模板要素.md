|                       |                                              |                       |
| --------------------- | -------------------------------------------- | --------------------- |
| **类别**                | **包含要素**                                     | **作用**                |
| **镜头（shot）**          | 景别（如近景、中景）、画幅比例、构图方式（如居中）                    | 定义画面的整体视角和布局，确定视觉焦点范围 |
| **主体（subject）**       | 对象（人物 / 物品）、外貌 / 材质、服饰 / 细节、状态（如全新、无瑕）       | 明确画面核心内容，展现主体的特征与质感   |
| **环境（environment）**   | 场景类型（室内 / 户外）、背景元素、氛围风格                      | 烘托主体，营造画面的整体基调与意境     |
| **光线（lighting）**      | 光线类型（柔光、硬光）、光源方向、光线效果（如突出光泽、制造阴影）            | 塑造主体的立体感、质感，控制画面明暗层次  |
| **相机（camera）**        | 焦距、光圈、拍摄角度                                   | 影响画面的景深、清晰度和主体呈现角度    |
| **角度（angle）**         | 拍摄视角（如低角度、平视、高角度）                            | 改变主体的视觉呈现效果，传递不同情绪    |
| **色彩风格（color_grade）** | 色调（暖 / 冷）、色彩处理（如高对比、轻微去饱和）、质感（如胶片颗粒、数字绘画感）   | 统一画面色彩语言，强化风格属性       |
| **风格（style）**         | 艺术风格（如超写实、印象派、赛博朋克）、领域风格（如商业摄影、时尚 editorial） | 界定画面的艺术表现形式与应用场景      |
| **画质（quality）**       | 分辨率、细节要求（如发丝清晰、齿轮纹理可见）                       | 保证画面的精细度与视觉冲击力        |
| **排除元素（negatives）**   | 需规避的视觉问题（如划痕、模糊、干扰元素）                        | 确保画面的纯净度与专业性          |
# AI 绘画提示词生成模板

制作一幅 [关键词 1，关键词 2] 主题的画作，风格限定为 [可替换为具体风格，如超现实主义油画、赛博朋克插画、水墨国风、复古漫画风等]；

视角构图采用 [可替换为具体视角，如低角度仰视、高空俯视、正面特写、侧面半身景、广角全景等]，突出主体在画面中的核心视觉地位；

主体描述为 [基于关键词补充细节，如 “通体覆盖银白色鳞片的独角兽，头顶螺旋状金色尖角，四肢肌肉线条流畅，尾端垂着蓬松的白色鬃毛”“覆盖着墨绿色植被的连绵山峰，山顶积雪在阳光下泛着微光，山间缠绕着淡蓝色云雾” 等]；

背景设定为 [可替换为具体背景，如 “深邃的星空背景，点缀着闪烁的彩色星云与流星轨迹”“开阔的草原背景，远处有蜿蜒的溪流与零星的野花” 等]；

细节修饰包括 [可替换为具体细节，如 “独角兽的眼角泛着淡紫色光晕，鬃毛间夹杂着细小的发光粒子”“山峰的岩石表面有清晰的纹理，植被间隐藏着小型动物的身影” 等]；

光影色调采用 [可替换为具体光影色调，如 “柔和的暖黄色侧光，整体色调偏温暖治愈”“强烈的明暗对比光，冷色调为主，局部有橙色光效点缀” 等]；

质量词为超高清分辨率、极致细节刻画、细腻纹理呈现、真实材质质感、专业级色彩搭配、无模糊边缘、无噪点。
