# Workflows

SOPs for recurring tasks.

## Obsidian Memory Sync

1. Start task: read _cortex/memory/*.md files
2. During work: note key decisions, preferences confirmed
3. End of session: update relevant memory files via MCP write_note
4. Verify: confirm changes persisted in vault

## Project Bootstrap

1. Check for AGENTS.md and MEMORY.md in project root
2. Read existing if present; skip if not
3. Create from template if missing
4. Initialize _cortex/memory entries for new projects

## Content Creation (Video)

1. Script draft -> review -> final
2. Assets: generate or source images/music
3. Render with Remotion/HyperFrames
4. QA: screenshot checks across viewports
